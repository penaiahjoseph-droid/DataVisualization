# Hospital Healthcare Data Analysis

Exploratory data analysis of a hospital admissions dataset, covering patient demographics, admission/discharge timing, length of stay, billing, and medical conditions.

## Files

| File | Description |
|---|---|
| `Hospital_Healthcare.ipynb` | Jupyter/Colab notebook with the full analysis and cell outputs |
| `hospital_healthcare.py` | Script export of the same notebook (auto-generated by Colab) |

## Data Source

`healthcare_dataset.csv` — 500 patient records, 9 columns:

- `Patient_ID` — unique patient identifier
- `Gender` — Male / Female
- `Age`
- `Medical_Condition` — diagnosis (e.g. Hypertension, Pneumonia, COPD, Stroke, Diabetes Type 2)
- `Admission_Date` — format `DD-MM-YYYY`
- `Admission_Type` — Urgent / Emergency / Routine (mixed casing/whitespace in raw data)
- `Medical_Code`
- `Billing_Amount`
- `Discharge_Date` — format `DD-MM-YYYY`

> **Note:** The CSV itself was not included in the uploaded files — only the notebook/script that processes it. The path referenced in code is `/healthcare_dataset.csv`.

## Workflow

The notebook follows a standard EDA pipeline:

1. **Load & inspect** — read the CSV, check shape `(500, 9)`, view `.describe()` and `.head()`.
2. **Missing values** — `isnull().sum()` (0 nulls found across all columns), followed by a `dropna()` safety step.
3. **Type conversion** — `Admission_Date` and `Discharge_Date` parsed to timezone-aware `datetime64[ns, UTC]` with `dayfirst=True`.
4. **Text cleaning** — `Admission_Type` stripped and lowercased for consistency.
5. **Feature engineering** — `Length_of_Stays` computed as `Discharge_Date - Admission_Date`, converted to integer days.
6. **Summary statistics** — descriptive stats for length of stay and billing amount.
7. **Categorical analysis** — value counts of `Medical_Condition`, and a `Medical_Condition × Gender` crosstab.

## Key Findings

- **Age:** ranges 22–78, mean ≈ 50.1 years.
- **Billing Amount:** ranges $2,300–$14,200, mean ≈ $7,249, std ≈ $3,199.
- **Length of Stay:** ranges 1–10 days, mean ≈ 2.74 days, median 2 days (right-skewed — most stays are short, with a long tail).
- **Top conditions by frequency:** COPD (34), Appendicitis (33), Stroke (33), Pneumonia (31), Heart Failure (30), Kidney Stone (28), Hypertension (28), Heart Attack (27), Fracture (22).
- **Gender skew by condition:** some conditions are heavily imbalanced by gender in this sample — e.g. Allergic Reaction (14 F / 1 M), Appendicitis (8 F / 25 M), Anxiety Disorder (2 F / 7 M) — worth deeper investigation or may reflect a small/synthetic sample.
